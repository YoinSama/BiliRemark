# BiliRemark

B 站网页端「用户备注」油猴脚本：给 UP 主打上**只有你自己能看见**的备注（备注名 / 标签 / 颜色 / 长文本），浏览时自动显示在昵称旁，并提供一个页内管理面板统一检索、编辑、导入导出。

**数据只存在本机浏览器扩展存储里，不联网、不上传、不同步到 B 站账号。**

> 当前支持：**视频页 UP 主**、**评论区（主楼 + 楼中楼）**、**opus 图文动态**、**视频卡片（首页 / 搜索 / 视频页右栏）**、**个人空间页（主页 + 动态页）**、**私信（会话列表 + 聊天窗头部）**、**关注 / 粉丝列表（关系列表行卡片）**。其余场景（旧版动态 / 直播 等）尚未实现，设置里对应开关置灰标注「后续版本」。

## 安装

**[▶ 一键安装 BiliRemark](https://raw.githubusercontent.com/YoinSama/BiliRemark/main/dist/BiliRemark.user.js)**

1. 先装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)（Violentmonkey / ScriptCat 也可，但只保证 API 交集内不崩）。
2. 点击上面的安装链接 → Tampermonkey 弹出安装页 → 点「安装」。
3. 打开任意 B 站视频页：右下角出现「备注」浮动按钮即安装成功。

装好后脚本会按 `@version` 自动检查更新，不用手动重装。

<details>
<summary>链接打不开？（国内网络）</summary>

`raw.githubusercontent.com` 在国内常被墙。备用地址（jsDelivr 从 GitHub 拉取，内容与上面完全一致）：

https://cdn.jsdelivr.net/gh/YoinSama/BiliRemark@main/dist/BiliRemark.user.js

或直接在 GitHub 页面上下载 `dist/BiliRemark.user.js`，拖进 Tampermonkey 管理面板。

</details>

**从源码构建：**

```bash
npm install && npm run build
```

产物为 `dist/BiliRemark.user.js`（单文件，运行期零外部依赖）。

## 使用

### 1. 视频页：给 UP 主加备注

1. 打开任意视频页，把**鼠标移到 UP 主昵称上** → 昵称旁出现一个小铅笔 ✎；
2. 点击铅笔 → 弹出编辑气泡；
3. 填写字段后保存 → **当前页面立即生效**，不用刷新。

| 字段 | 说明 |
|---|---|
| 备注名 | 显示在昵称旁的主文本，≤50 字 |
| 标签 | ≤5 个，每个 ≤16 字；输入后按回车添加 |
| 颜色 | 8 个预设色 + 取色器；选「跟随主题色」则跟随 B 站 / Evolved 主题 |
| 长文本 | ≤500 字，只在管理页和 hover 时显示 |

**修改 / 删除已有备注**：直接点击昵称旁的备注标签，打开同一个编辑气泡（内有「删除」按钮）。

> 备注标签是浮层渲染的，**不会插进 B 站自己的容器**，因此不会影响页面加载与布局。空间不够时会自动收起标签胶囊（只显示备注名）。

### 2. 评论区：评论者旁的备注

视频页评论区（主楼与楼中楼回复）的**评论者昵称旁**：

- 已备注的评论者：昵称旁显示备注标签，点击即可编辑；
- 未备注的评论者：hover 昵称出现小铅笔 ✎，点击写备注；
- 「展开更多回复」加载出来的新评论会自动补上，无需刷新。

> 评论区是多层 Shadow DOM 组件，备注标签同样走页面级浮层渲染，**不会写进 B 站的组件内部**。

### 3. 动态页：opus 图文动态发布者旁的备注

打开 `https://www.bilibili.com/opus/<id>` 图文动态，**发布者昵称旁**显示备注标签 / hover 铅笔，规则与视频页一致。动态页的评论区同样支持（见上一节）。旧版 `t.bilibili.com` 动态详情 / 转发动态暂未支持。

### 4. 视频卡片：首页 / 搜索 / 右栏推荐

首页 feed、搜索结果、视频页右侧「接下来播放」的**卡片作者行**显示备注徽标：

- 已备注的 UP：作者行末尾显示备注标签，点击即可编辑；
- 未备注的 UP：hover 作者行出现小铅笔 ✎，点击写备注；
- 首页无限滚动新加载的卡片自动补上，无需刷新。

> 卡片场景的铅笔是**按需创建**的：没有 hover 过的卡片不占用任何浮层条目，长时间滚动也不增加额外开销。

### 5. 空间页：备注卡片

打开 `https://space.bilibili.com/<mid>`（主页）或 `https://space.bilibili.com/<mid>/dynamic`（动态页），右侧侧栏会自动出现同一张「备注」卡片（固定在公告卡上方）：

- **已有备注**：显示备注名、标签、正文与更新时间，点「编辑备注」可**在卡片内直接改**；
- **还没有备注**：显示空态 +「添加备注」按钮。

卡片内编辑快捷键：`Esc` 取消 · `Ctrl+Enter` 保存。
卡片底部「高级编辑」会打开完整的编辑气泡（可改颜色、删除记录）。

### 6. 备注管理器（统一管理）

三种打开方式，任选其一：

| 方式 | 说明 |
|---|---|
| 浮动按钮 | 页面右下角「✎ 备注」 |
| 油猴菜单 | 点击 Tampermonkey 图标 →「打开备注管理器」 |
| 快捷键 | 默认 `Alt+R`（可在设置里改，**刷新页面后生效**） |

管理器里可以：

- **搜索**：备注名 / 昵称 / mid / 正文 / 标签，模糊匹配实时过滤；
- **筛选**：标签 · 来源场景 · 有无正文；
- **排序**：更新时间 / 创建时间 / 备注名 / mid，可切升降序；
- **分页**：默认 50 条/页（设置里可调 10~500）；
- **新增**：点「新增」手动输入 mid，给还没在页面上遇到的人先建备注；
- **删除**：单条或勾选多条批量删除，**二次确认**，删除后 **5 秒内可撤销**（toast 上点「撤销」）。

键盘快捷键：`/` 聚焦搜索框 · `Esc` 关闭 · `Delete` 删除已勾选项。

### 7. 导入 / 导出

**导出**：管理页「导出」→ 选 **JSON**（完整备份，可再导入）或 **CSV**（表格可读，**不能导入**）。
导出时会记录「上次导出时间」。

**导入**：管理页「导入」→ 选择 JSON 文件**或**直接粘贴 JSON → 选择合并策略 → 查看预览 → 确认写入。

| 合并策略 | 行为 |
|---|---|
| 按 mid 合并，保留较新（默认） | 同一 mid 谁 `updatedAt` 新留谁 |
| 仅新增，不覆盖 | 已有的记录不动，只加不存在的 |
| 覆盖全部 | 以导入文件为准，本地多出来的会被删除（会提示删除数量） |

> 导入和「清空数据」执行前都会**自动写一份备份**到 GM 存储（`brmk.data.backup.*`）。
> 数据只在本机，**换设备 / 清浏览器数据前记得先导出**。

### 8. 暂停显示

两种方式，数据都会保留：

- 油猴菜单 →「暂停 / 恢复备注显示」；
- 管理页「设置」→「启用备注显示」开关。

### 9. 其他

- 打开管理器的快捷键、每页条数、面板配色（跟随页面 / 强制深色 / 强制浅色）、面板层级、导出提醒间隔、DOM 观察去抖等，都在管理页「设置」页签里。
- 打开「调试模式」后，进入页面会自动弹出**选择器体检面板**，可查看各场景的选择器命中情况并一键复制诊断信息（排查改版失效时用）。
- 脚本运行时会在 `window.__biliRemark__` 上暴露少量调试入口（`rescan` / `openManager` / `doctor` 等），不含任何备注数据。
